# Image Index — Haps Club

Claude-readable catalog of brand assets in this folder.

## How to use with Claude

In any future Claude chat, share this URL:

```
https://raw.githubusercontent.com/Hilex2030/haps-club-assets/main/images/INDEX.md
```

Then ask Claude to "load the index and use the listed images".

## When to use which variant

- **Light backgrounds (cream, white, pastels)** → `haps-club-logo.svg` (navy)
- **Navy or dark photo backgrounds** → `haps-club-logo-white.svg` (off-white)
- Both files are scalable SVG, hand-lettered "Haps" connected to bold "CLUB" wordmark — never recreate as text or substitute with a fabricated monogram.

## Adding new images

1. Upload the file to `/images/` (via GitHub web UI or git)
2. Edit this file and add a row to the catalog table above
3. Commit — Claude can now find and use the image
